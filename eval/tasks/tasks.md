# Wirelith learnability eval tasks

Two task sets. Each is given to a model together with the one-page AI spec and nothing else. The model writes its answer once, with no checking or revision.

## Task set A

Write five wireframes in Wirelith. Put each in its own ```wirelith code block, in this order, with nothing else in your answer except a one-line heading before each block.

1. A phone sign-up screen: name, email, password, a checkbox to accept the terms, and a button.
2. A desktop account settings page with tabs (Profile, Security, Notifications). Show the Profile tab: an avatar, fields for name, email and a short bio, a time zone dropdown, and Save and Cancel buttons aligned to the right.
3. A desktop email inbox: a left sidebar with folders (one of them selected, one with an unread count), a top bar with a search field and a Compose button, a table of messages with sender, subject and date, and Previous / Next buttons under it.
4. A phone checkout flow of three screens: Cart, Shipping address, Order confirmed. Buttons move between the screens. Also show the Shipping address screen in an error state where the postcode is invalid.
5. A desktop task board for a made-up product. A header with the product name, a search field, a filter button with an icon and a "New task" button. Three columns (To do, In progress, Done), each holding two or three task cards with a title, a priority badge and the assignee's avatar. "New task" opens a dialog with a title field, a description field, an assignee dropdown and a priority choice. Clicking the first card opens a side panel with the task's details and a comment box. Add two notes explaining two of the elements. Use the dark theme.

## Task set B

Write five wireframes in Wirelith. Put each in its own ```wirelith code block, in this order, with nothing else in your answer except a one-line heading before each block.

1. A phone "Add contact" form: first name, last name, phone number, email, a "Favourite" switch, and Save.
2. A desktop pricing page: a heading, a monthly / yearly switch, and three plan cards side by side (Free, Team, Business), each with a price, a short list of features and a button. The Team plan is the highlighted one.
3. A desktop admin "Users" page: a header with the page title and an "Invite user" button, a row of filters (search, role dropdown, status dropdown), a table of users with name, email, role, status and last seen, and a second version of the same page for when no users match the filters.
4. A tablet booking flow for a made-up dental clinic: choose a service, pick a date and time, enter your details. Buttons move forward and back between the three screens. The last screen's "Confirm booking" button opens a confirmation dialog, whose "Done" button returns to the first screen.
5. A desktop file manager for a made-up product. A left sidebar with locations, breadcrumbs for the current folder, a toolbar with Upload and "New folder" buttons and a search field, and a grid of file cards (a picture placeholder, a file name and a size). Selecting a file opens a details panel on the right with its properties and Download and Delete buttons. Delete opens a confirmation dialog. Also show the same page while it is loading, and when loading failed with a retry button. Add two notes explaining two of the elements. Use the blue monochrome theme.
